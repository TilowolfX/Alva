Arquitectura del sistema

Las capas que seperan tus programas del hardware real.

Linux organiza el software en dos mundos principales para garantizar la seguridad y estabilidad.

User Space: Donde viven tus aplicaciones (Navegador, Terminal,Juegos,Wps office). Tienen acceso limitado por seguridad

Kernel Space: Donde vive el nucleo. Tiene el control total sobre la CPU, la Ram y los discos.

¿Comó interactuan las aplicaciones con el sistema operativo?

Las aplicaciones interactúan con el sistema operativo mediante llamadas al sistema (system calls), que son funciones que permiten solicitar servicios al núcleo del sistema operativo. A través de estas llamadas, las aplicaciones pueden acceder a recursos como memoria, archivos, dispositivos de hardware, red y procesamiento. El sistema operativo actúa como intermediario, administrando y controlando los recursos para garantizar que los programas funcionen de manera segura y eficiente sin acceder directamente al hardware.

Relación entre el hardware y el software

En Linux, la relación entre el hardware y el software se realiza a través del kernel, que actúa como intermediario entre ambos. El hardware incluye los componentes físicos de la computadora, como el procesador, memoria, disco y dispositivos de entrada o salida, mientras que el software son los programas y aplicaciones que utiliza el usuario. Linux permite que el software se comunique con el hardware mediante controladores (drivers), administrando recursos como la memoria, la CPU y los dispositivos para que el sistema funcione correctamente y de manera eficiente.
