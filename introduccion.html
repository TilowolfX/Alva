Introducción al sistema operativo

¿Qué es linux y por que todo el mundo habla de el?

Linux no es solo un sistema operativo; es el motor que mueve internet, supercomputadoras y casi todos los servidores del planeta. A diferencia de Windows o MacOs, Linux es de "Código abierto", lo que significa que cualquiera puede verlo, modificarlo y mejorarlo.

El kernel

El corazon del sistema que gestiona el hardware.

Distribucion (Distro)

El kernel + Herramientas + Entorno Grafico (Ej.: Debian, Ubuntu).

¿Cual es la funcion de linux?

Gestión de Hardware y Recursos:

El núcleo (kernel) administra la CPU, la memoria RAM y los dispositivos periféricos (Wi-Fi, Bluetooth, impresoras, tarjetas gráficas).

Multiusuario y Multitarea:

Permite que varios usuarios ejecuten múltiples tareas simultáneamente, lo que lo hace ideal para servidores y entornos compartidos.

Gestión de Archivos y Permisos:

Proporciona un sistema jerárquico de archivos con seguridad estricta para controlar el acceso a los datos.

Seguridad y Estabilidad:

Gracias a su diseño, es menos vulnerable a malware y virus, ofreciendo una plataforma robusta.

Automatización y Redes:

Facilita la automatización de tareas y posee capacidades nativas para la gestión de redes de datos.

Flexibilidad y Personalización:

Al ser código abierto, permite modificar la interfaz y las funcionalidades para adaptarse a necesidades específicas.
