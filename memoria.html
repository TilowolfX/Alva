Gestión de Memoria RAM

RAM Física vs Virtual: El juego de malabares de Linux.

¿Qué es el SWAP?

Es un espacio en el disco duro que Linux usa como una "extensión" cuando la memoria RAM física está llena. Es mucho más lenta, pero evita que el sistema se cuelgue.

Memoria Virtual y Caché:

Linux utiliza todo el espacio RAM disponible. Si hay RAM libre, la usa para caché (buffer/cache) para acelerar la lectura de archivos. Esta caché se libera inmediatamente si un programa necesita RAM física.

Paginación y Intercambio (Swap):

La gestión se basa en paginación: la memoria se divide en "páginas" pequeñas. Si la RAM física se llena, el núcleo mueve páginas de memoria menos utilizadas al espacio swap (disco), liberando RAM para procesos activos.

Gestión del Núcleo:

Utiliza funciones como kmalloc() para asignar memoria física de manera eficiente, minimizando la fragmentación.

Monitoreo:

Se puede visualizar la gestión de memoria usando comandos como free -h (para ver memoria libre, usada y en búfer) o top/htop para ver el uso en tiempo real.
