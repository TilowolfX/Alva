¿Qué es sudo?

Sudo (Super user Do) permite a un usuario normal ejecutar comandos con los privilegios del superusuario (root). Es la barrera de seguridad que evita que borres el sistema por error.

Registra cada acción en logs

En Linux, el control de usuarios y permisos de archivos permite proteger la información y administrar el acceso a los recursos del sistema. Cada archivo y directorio tiene un propietario y permisos definidos para tres tipos de usuarios: propietario, grupo y otros usuarios. Los permisos básicos son lectura (r), escritura (w) y ejecución (x), los cuales determinan quién puede ver, modificar o ejecutar un archivo. Linux utiliza este sistema de seguridad para evitar accesos no autorizados y mantener la integridad del sistema.
